# Contributing

This is a personal coursework repository, not a collaborative project. It is not open to feature requests or content suggestions, since the notes reflect my own understanding of the module material. Corrections are welcome.

## What belongs here

- A factual error in a note or lab writeup
- A broken link or a notebook cell that no longer runs
- A typo or formatting fix

## What does not belong here

- New topics, sections or notes not covered by the module
- Rewrites of existing notes for style rather than accuracy
- Pull requests adding unrelated content

## Reporting a correction

Open an issue with:

- Which week and file
- What is wrong
- What it should say instead, if known
